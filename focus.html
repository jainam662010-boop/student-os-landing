The timer

A timer that can't drift.

Most timers count down by subtracting a second every second. Miss a frame in the background and the session is wrong. Student OS stores the end time instead, so the number on screen is always the real number.

Pick 25, 60, 90 or 120 minutes. Pause, resume, close the app — the session picks up exactly where it should.
